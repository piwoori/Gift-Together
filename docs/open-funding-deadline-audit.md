# 배포 전 OPEN 펀딩 마감 시각 점검

권한이 있는 운영자가 읽기 전용 계정으로 [점검 SQL](open-funding-deadline-audit.sql)을 실행합니다. SQL은 읽기 전용 트랜잭션에서 OPEN 펀딩의 ID와 시각만 조회합니다. `*_utc` 열은 DB 세션 시간대와 관계없이 UTC로 표시됩니다.

| 결과 | 해석 |
| --- | --- |
| `interpretation_changes_expiry` | 현재 시각 기준으로 두 해석의 만료 여부가 다릅니다. 배포 전에 우선 확인합니다. |
| `due_under_both` | 두 해석 모두 현재 만료 대상입니다. 이 결과만으로 원래 의도한 마감이나 OPEN으로 남은 이유를 판단할 수 없습니다. |
| `future_under_both` | 두 해석 모두 현재는 미래입니다. 나중에 실제로 마감되는 시각은 다를 수 있습니다. |

`expired_at`은 오프셋이 없는 값이므로 이 결과만으로 원래 시간대를 복원할 수 없습니다. UTC는 비교 시나리오이며, 기존 브라우저나 API 호출자가 다른 시간대를 사용했을 수도 있습니다. 요청 로그, 입력 당시 시간대, 사용자에게 안내된 마감일 등 외부 근거를 확인합니다. `created_at`과 `updated_at`은 참고용이며 기존에는 JVM 시간대로 기록될 수 있어 시간대 판별 근거로 단독 사용하지 않습니다.

한국 시간 입력이 확인된 행은 그대로 호환됩니다. 출처가 불명확하거나 다른 시간대 입력이 확인된 OPEN 펀딩은 배포 전에 처리 방침을 정합니다. 앱에는 기존 데이터 자동 변환과 마이그레이션을 추가하지 않습니다. 새 펀딩·참여·모의 결제에 기록되는 시각은 한국 시간이며, 같은 작업에서는 한 시각을 공유합니다.
